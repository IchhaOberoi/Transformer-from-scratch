# Transformer from Scratch

This project replicates the Transformer architecture from the paper [“Attention Is All You Need”], implemented entirely from scratch using PyTorch.

## Files

- `model.py` — Transformer architecture (encoder, decoder, attention mechanisms)
- `train.py` — Training and validation loop
- `dataset.py` — Dataset loading and preprocessing

## Dataset

- Used the **Hugging Face 🤗 Datasets** library
- Dataset: **Opus Books** — a parallel corpus for machine translation tasks (e.g., English ↔ Italian)

## 🔧 Tech Stack

- Python
- PyTorch
- TorchText
- Hugging Face Datasets
